03 / DIGITAL COMMUNICATION

Different wires.
Different conversations.

Read the timing relationships, not just the names on a connector. These are representative simulations, not captured traffic.

Asynchronous · TX / RX · common reference

UART
One wire per direction. A shared baud rate.

8N1 example: idle high, a low start bit, eight data bits sent least significant bit first, then a high stop bit. Byte 0x53 is shown.

No clock wire. Both ends agree on baud rate and framing. Logic-level UART is distinct from RS-232 electrical signaling.

Synchronous · SDA / SCL · open-drain

I²C
A clock, a data line, many addresses.

A representative data byte plus acknowledge. SDA stays stable while SCL is high, except at START and STOP. The receiver drives the ninth clock’s ACK low.

Pull-ups establish the high level. Real transactions also carry an address and read/write bit; clock stretching and arbitration are omitted here.

Synchronous · SCLK / MOSI / MISO / CS

SPI
A shared clock. Two directions at once.

Mode 0: the clock idles low; receivers sample on rising edges. Chip select is active low. MOSI shows 0xA5 and MISO shows 0x3C, most significant bit first.

This is one common SPI mode. Clock polarity, phase, framing and select behavior must match the peripheral’s datasheet.

Differential · CAN_H / CAN_L · shared bus

CAN bus
The difference carries the message.

Illustrative high-speed CAN: recessive levels are both near 2.5 V; a dominant state raises CAN_H near 3.5 V and lowers CAN_L near 1.5 V. Dominant is logical 0.

PulseShift’s CAN work is experimental and receive-only. Listen-only suppresses transmission and acknowledgements, but does not qualify wiring, a transceiver or automotive protection.

ARDUINO UNO / GPIO & TIMEC++

A small loop, without blocking.

#include <Arduino.h>
uint32_t previous = 0;
bool lit = false;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  const uint32_t now = millis();
  if (now - previous >= 500) {
    previous = now;
    lit = !lit;
    digitalWrite(LED_BUILTIN, lit);
    Serial.println(lit);
  }
}

Unsigned subtraction keeps this millis() interval comparison valid across wraparound. This is software scheduling, not a hard real-time guarantee.

ARDUINO UNO / PWM & SENSINGC++

From an ADC code to a duty cycle.

#include <Arduino.h>

void setup() {
  pinMode(9, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  const uint16_t raw = analogRead(A0);
  const uint8_t duty = raw >> 2;
  analogWrite(9, duty);
  Serial.println(raw);
  delay(20);
}

Arduino Uno: A0 supplies a 10-bit ADC code; pin 9 supports 8-bit analogWrite PWM. PWM is not an analog voltage output. Other boards have different pins, ranges and APIs.

ARDUINO UNO / INTERRUPTSC++

Notice the edge. Do the work later.

#include <Arduino.h>
volatile uint16_t edges = 0;
void onRise() { ++edges; }

void setup() {
  pinMode(2, INPUT_PULLUP);
  Serial.begin(115200);
  attachInterrupt(digitalPinToInterrupt(2),
                  onRise, RISING);
}

void loop() {
  noInterrupts();
  const uint16_t snapshot = edges;
  interrupts();
  Serial.println(snapshot);
  delay(100);
}

Arduino Uno: pin 2 supports an external interrupt. Keep the ISR short. Copy the shared 16-bit count atomically on the 8-bit AVR; this example counter wraps at 65,536.
