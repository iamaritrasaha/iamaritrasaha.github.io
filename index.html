SeeDL

The Neural Observatory
Scientific visualization / Open source

Look inside the model.

I’m building SeeDL to make deep-learning models and quantum systems easier to inspect. It turns captured values into interactive views: individual neurons and their signed connections, execution graphs, attention routing and gradient diagnostics.

Explore the result in a notebook or export it to a browser. The Python core has no required third-party dependencies; PyTorch, Plotly and Qiskit are optional integrations.

Python · PyTorch · Plotly · Qiskit · Scientific visualization

GitHub repository ↗ Official website ↗ PyPI package ↗ Documentation ↗
Inside the observatory +
Inspect the computation.

The artwork is conceptual. SeeDL’s interactive viewers use captured model values, including activations and signed connection weights. Execution tracing records the model’s graph and tensor metadata; attention views show routing weights, rather than a causal explanation.

SeeDL exports interactive HTML and SVG for use beyond a running notebook. Its playground includes neural-network, attention and quantum-system examples. The portfolio uses an illustrated preview; the full viewers run on SeeDL’s website.

Infera

Data analysis / Independently built

Turn data into evidence.

Exploring a dataset should leave a trail you can inspect. I built Infera to turn CSV files into descriptive statistics, correlations, a regression model and a downloadable Markdown report.

The Python engine does the computation. A Next.js interface presents the findings and their limits, without an external AI API.

Python · FastAPI · pandas · scikit-learn · TypeScript

View source ↗
Method, decisions & current limits +
Keep evaluation separate.

I fit missing-value imputation on training data only, then evaluate linear regression on the held-out split. The interface exposes coefficients and errors so the result can be examined. A random split assumes independent observations; correlation does not establish causation.

A focused local application.

The current implementation supports one regression algorithm. Datasets live in process memory and disappear on restart. Public deployment needs authentication and API hardening. No production deployment or user count is claimed.

PulseShift

Embedded C++ / Software prerelease

From software to signal.

I’m building ESP32 firmware for a six-LED motorcycle shift light: configurable visual styles, progressive output and explicit blanking when valid data goes missing.

The standalone demo runs without a motorcycle. Arduino IDE packaging, Wokwi simulation and passive CAN investigation tools support development.

C++ · ESP32 · WS2812B · Arduino · TWAI

View firmware ↗
Signal integrity & qualification +
Missing data stays missing.

Vehicle mode never substitutes synthetic RPM when real data is absent. Receive-only CAN integration remains experimental. The motorcycle profile is unverified, live decoding is disabled, and physical qualification is pending.

Software first, bench validation next.

The software prerelease includes the standalone demo. Simulation does not validate physical CAN, electrical protection or motorcycle compatibility. This portfolio preview illustrates LED progression only.

Orion

LLM research
Research in progress

What changes when
a model learns?

Fine-tuning can teach a model something new while weakening what it already knew. Orion is where I investigate that trade-off through inference notebooks, spectral checks and small-model experiments.

I’m using Python and PyTorch to study LoRA interventions on SmolLM2-360M. The model experiments stay separate from application work, so I can inspect what actually changed.

LoRA, in one line

W′ = W + (α/r)BA

W stays frozen. A and B are learned.
rank(BA) ≤ r: a smaller update to a larger model.

Python · PyTorch · Transformers · LoRA / PEFT

What the experiment actually said

Removing “intruder” directions did not substantially recover the forgetting gap in one small-model experiment.

A narrow result that challenged the initial explanation. No final base model has been selected.

Intervention before explanation.

I compare interventions instead of treating correlation as a cause. Foundations work continues; this result does not generalize to every model. Orion’s source is not public.

The accompanying surface illustrates a separable weight update, ΔW = abᵀ. It is a geometric study of adaptation, not measured weights or an Orion benchmark.

One workflow.
Two devices.

I want my phone and Linux desktop to work together. Relay brings nearby devices, secure pairing and file transfers into one GNOME-oriented application.

I built a Rust protocol engine and a shared device layer behind Flutter, with networking and cryptography off the UI thread.

Flutter · Rust / Tokio · D-Bus · Mutual TLS

Vyren

Follow the connection.

I want to know which application opened a connection, where it went and how certain that attribution is. Vyren connects kernel and packet evidence with live telemetry and local history.

I separated the Rust telemetry engine, Flutter interface and protected inspection helpers. Unknown evidence stays unknown.

Accounting for what was observed

Bobserved = Battributed + Bunknown

Bytes assigned to an application, plus bytes we cannot assign.
Unknown stays in the equation.

Rust · Flutter · Unix sockets · SQLite
