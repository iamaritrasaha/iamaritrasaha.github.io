SeeDL

The Neural Observatory
Scientific visualization / Open source

Look inside the model.

I’m building SeeDL to make deep-learning models and quantum systems easier to inspect. It turns captured values into interactive views: individual neurons and their signed connections, execution graphs, attention routing and gradient diagnostics.

Explore the result in a notebook or export it to a browser. The Python core has no required third-party dependencies; PyTorch, Plotly and Qiskit are optional integrations.

Python · PyTorch · Plotly · Qiskit · Scientific visualization

The artwork is conceptual. SeeDL’s interactive viewers use captured model values, including activations and signed connection weights. Execution tracing records the model’s graph and tensor metadata; attention views show routing weights, rather than a causal explanation.

QUANTA

Scientific computing / Interactive visualization

The shape of a possibility.

What does an equation let us see? I built QUANTA to connect atomic states, probability distributions, energy levels and spectroscopy in an interactive scientific observatory covering all 118 elements.

Analytical hydrogen solutions sit alongside screened approximations for many-electron atoms, empirical reference levels where available and theoretical predictions for superheavy elements. Each model has a scope; the interface makes those limits part of the explanation.

TypeScript · React · Three.js · Scientific modeling

Explore QUANTA ↗View source ↗
Models, mathematics & current limits +
Make the model inspectable.

The normalized radial convention gives P(r) = r² |Rₙₗ(r)|², with ∫₀∞ P(r) dr = 1. The sketch uses the analytical hydrogen 1s and 2s states. A probability distribution describes possible measurements, not a classical electron orbit.

QUANTA connects state selection to radial functions, angular shapes and energy differences. Derived wavelengths do not by themselves establish transition strength or probability.

Different atoms, different fidelity.

Hydrogen uses analytical solutions of the ideal nonrelativistic model. Many-electron views use effective-charge screening and approximate orbital shapes, with empirical NIST reference levels where available. Superheavy states include theoretical predictions; missing measured spectra remain explicit. These are not exact many-electron solutions for every element.

Orion

LLM research
Research in progress

What changes when
a model learns?

Fine-tuning can teach a model something new while weakening what it already knew. Orion is where I investigate that trade-off through inference notebooks, spectral checks and small-model experiments.

I’m using Python and PyTorch to study LoRA interventions on SmolLM2-360M. The model experiments stay separate from application work, so I can inspect what actually changed.

LoRA, in one line

W′ = W + (α/r)BA

W stays frozen. A and B are learned.
rank(BA) ≤ r: a smaller update to a larger model.
