## Existing architecture and content

This is a static, single-page semantic HTML/CSS portfolio with progressive ES-module JavaScript, a separate 404 page and no production dependencies. There is no React, TypeScript, backend, contact-form endpoint or routing library. Native fragments and disclosures provide navigation. GitHub Pages serves the root; an optional Python build copies the public assets to `dist/`. No repository CI workflow is present.

The local Newsreader, Inter and JetBrains fonts, their licenses, ivory/charcoal/cobalt tokens, dark/system themes, visibility-gated animation and reduced-motion controls already form a coherent design system. The hero contains a real trained digit classifier with inference and gradient calculations. Orion's SVG weight-space illustration, SysAI's diagnostic flow and Relay/Vyren's responsive artwork are working features worth retaining.

The featured projects remain Orion, SysAI, Relay and Vyren, with their development states and boundaries unchanged. Aether, Orbis, Arthrekha, VECTOR, QUANTA, Veyra, Serein and earlier explorations remain in the index. Foresight Labs context, email address, GitHub links, model provenance and ownership statements were preserved. No new qualifications, C++ experience, achievements, numbers or project claims were invented.

## Implemented design and engineering

IBM's design reference informed a legible reading scale, flat actions, one purposeful accent and clear touch targets. Linear's reference reinforced restraint and real technical content. Neither reference's palette or fonts replaced the portfolio's identity. The concept remains an engineer's fieldnotes: the trained classifier demonstrates the learning process, and each project tells a specific engineering story.

- A stronger hero pairs a flat cobalt work action with the real GitHub profile. Mobile copy uses the full reading column; tablet uses an intentional stacked composition.
- Four project shortcuts expose the breadth of work before the detailed stories. At smaller widths they form two columns and use real section anchors.
- Project, archive, practice, disclosure, about and contact prose share a 16px reading scale. Navigation and ordinary actions have at least 44px height. Dense mathematical annotations and the existing 26px neuron targets retain their specialized layout.
- Tablet SysAI and paired project layouts stack. Archive hover feedback changes color without moving the reading columns. New controls use native elements, explicit focus, touch manipulation, and reduced-motion-safe transitions.
- Fragment navigation preserves native scrolling/history while moving keyboard focus to the destination. Email copying is an enhancement with a status region, a blocked-clipboard recovery message and the original mailto fallback.
- Pre-publication review hides the entire copy-control row when JavaScript or the Clipboard API is unavailable, avoiding an empty contact gap. Both fallbacks are covered by browser assertions. Reports omit machine-specific absolute paths.
- The local Node server handles nested 404s, HEAD and unsupported methods, blocks private paths and traversal, and binds to loopback. Python test/build scripts remain intact behind an interpreter resolver. A regression test found an encoded-backslash traversal bug in the new server; the final implementation rejects it.
- Added browser QA config and 15 regression scenarios. Source size checks and all 17 existing mathematical/physics/theme tests remain intact. Updated changed asset query versions and added generated QA directories to `.gitignore`.

## Visual review

Baseline and updated full-page screenshots at 1440, 768 and 390px are saved outside the repository as local review artifacts. Automated per-viewport screenshots and failure traces are regenerated under ignored `test-results/`. Neither screenshots nor machine-specific artifact locations are included in the commits.

Round 1: the baseline first screen was dominated by the title, but the mobile intro read like a narrow annotation. Hero=editorial split / Orion=research spread / SysAI=diagnostic essay / Relay-Vyren=offset pair / archive=index / practice=list / about=essay / contact=invitation. The live thing is the real digit classifier. The top issues were small reading text, mobile hierarchy and difficult project access.

Round 2: the revised mobile hero has a two-line title, full-width body and visible actions. Desktop retains the editorial split. Visual inspection exposed the tablet title still wrapping and the SysAI diagram sharing too narrow a column; both were stacked. Project shortcuts and larger prose improve scanning. The existing dense neural annotations and the long page remain tradeoffs. No numeric Taste score or inspector certification is claimed because its required browser gate could not run and its aesthetic caps conflict with the preserved identity.
